# HTML Media Player

A clean and organized HTML5-based media player project that showcases video game trailers and music tracks using native browser media elements.

## Overview

This project provides a web page, `MediaPlayer.html`, featuring a curated collection of embedded video players with poster images alongside an audio player section. It utilizes native HTML5 `<video>` and `<audio>` elements with built-in playback controls.

## Features

- **Video Player Section**: Embedded video trailers with custom poster previews for each title.
- **Audio Player Section**: Dedicated HTML5 audio players with controls for 6 music tracks.
- **Organized Directory Structure**: Clean separation of media assets into `Videos/`, `Audio/`, and `Images/` directories.
- **Native Browser Playback**: Fully functional without external dependencies or third-party player libraries.

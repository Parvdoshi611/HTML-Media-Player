# HTML Media Player

A simple HTML-based media player project that displays multiple video trailers using native browser media elements.

## Overview

This project contains a basic web page, `MediaPlayer.html`, with a collection of embedded video players for popular game trailers. It uses the HTML5 `<video>` element and includes a section for audio players that is currently prepared for future use.

## Included media

The project currently includes the following video files:

- Ghost of Tsushima
- The Last of Us Part I - Announce Trailer
- God of War
- Horizon Zero Dawn Remastered
- Red Dead Redemption 2 Trailer
- Cyberpunk 2077

## Project structure

- `MediaPlayer.html` - Main media player page
- Video files in the project root
- `README.md` - Project documentation

## Future updates

The following improvements are planned:

1. Add posters to the video section
2. Add audio tracks and audio player functionality
3. Organize files into dedicated folders such as `videos`, `audio`, `images`, and `scripts` for a cleaner layout

## Usage

Open `MediaPlayer.html` in a browser to view the media player page.
